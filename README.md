# The Robot Pickup Line Championship

Entry for the make.fun bounty
`u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`.

## The line

> I checked my error logs — the only bug I found is that I can't stop thinking about you.

87 characters, one line, UTF-8.

## Why this line

The joke grows out of being a machine: a robot does not confess feelings,
it reads its error logs — and the "bug" it finds is a crush. The turn is
unexpected (a diagnostic that returns romance instead of a fault), every word
earns its place, and it stays charming rather than creepy: a robot that is
honest about its own malfunction.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
The program self-checks the competition gate before writing: 1–200
characters, a single line, not only whitespace. Requires Python 3 only,
no third-party dependencies.
